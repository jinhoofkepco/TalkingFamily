# 텔레그램 봇으로 두 휴대폰 연결하기

엄마·아빠·아들·딸 등 여러 명이 대화하려면 [0.5.0 가족 대화방 안내](family-chat.md)를 따르세요. 아래 1:1 연결은 기존 위치 공유와 칭찬판을 함께 사용하는 보호자·자녀용이며 가족방과 함께 유지할 수 있습니다.

TalkingFamily는 휴대폰마다 텔레그램 봇 하나를 연결해 앱끼리 대화·위치·칭찬 기록을 주고받습니다. 직접 운영하는 가족 서버, 가족 서버 주소, 가족 연결 키는 필요하지 않습니다. 두 휴대폰 모두 인터넷에 연결되어 있어야 합니다.

## 1. 봇 두 개 준비

1. 텔레그램에서 공식 [@BotFather](https://t.me/BotFather)를 엽니다.
2. `/newbot`으로 **자녀용 봇**과 **보호자용 봇**을 각각 만듭니다. 봇마다 이름, `bot`으로 끝나는 고유한 사용자명, 봇 토큰이 생깁니다.
3. BotFather에서 각 봇의 설정을 열어 **Bot-to-Bot Communication Mode**를 **두 봇 모두** 켭니다.

텔레그램은 이 모드가 양쪽 봇에 켜져 있을 때 상대 봇의 `@사용자명`으로 직접 메시지를 보낼 수 있습니다. [Telegram 공식 안내](https://core.telegram.org/bots/features#communication-in-private-chats)

토큰은 봇의 비밀번호입니다. 채팅이나 스크린샷으로 공유하지 말고 해당 휴대폰의 앱 입력칸에만 붙여 넣으세요. 같은 봇을 다른 앱이나 자동화에서 동시에 수신용으로 사용하지 마세요.

## 2. 휴대폰에 입력

| 항목 | S23 일반 | S23 울트라 |
| --- | --- | --- |
| 역할 | 자녀 | 보호자 |
| 이 휴대폰의 텔레그램 봇 토큰 | 자녀용 봇 토큰 | 보호자용 봇 토큰 |
| 상대방 봇 사용자명 | 보호자용 봇의 `@사용자명` | 자녀용 봇의 `@사용자명` |

앱의 안내를 보호자와 자녀가 함께 읽고 확인한 뒤 **우리 가족 연결하기**를 누르세요. 상대방 봇의 토큰은 입력하지 않습니다. 휴대폰의 봇 토큰은 Android Keystore로 보호해 저장됩니다.

## 3. 메시지 수신과 연결 확인

두 휴대폰에서 **가족 연결 → 메시지 수신**을 켜 두세요. 수신 중에는 휴대폰 알림이 표시되며 설정이나 알림에서 끌 수 있습니다. 별도의 Firebase 설정은 필요하지 않습니다.

- 자녀: 대화 입력칸에 정확히 `설정`을 보내면 설정 메뉴가 열립니다. **가족 연결**을 선택하세요.
- 보호자: **칭찬판 → 가족 연결**에서 확인합니다.

양쪽 앱을 열어 둔 상태에서 자녀가 짧은 인사를 보내고 보호자가 답장을 보내 보세요. **상대 기기 수신**은 상대 앱이 기록을 받은 상태이며, 사람이 읽었다는 뜻은 아닙니다. 상대 앱이 받을 때까지 **전송 대기**로 보일 수 있습니다.

화면이 꺼져 있을 때도 받으려면 수신을 계속 켜 두어야 합니다. 절전, Android의 백그라운드 제한, 강제 종료, 재부팅과 인터넷 끊김으로 수신이 멈추거나 늦어질 수 있습니다. 항상 켜진 서버와 같은 수신 보장은 없습니다. 이때는 양쪽 앱을 다시 열고 수신 설정과 인터넷 연결을 확인하세요. 장시간 꺼져 있던 기기는 앱을 열어 새로 고침한 뒤 전송 상태를 확인하세요.

## 4. 위치 공유는 별도로 동의하고 켜기

연결만 해서는 자동 위치 공유가 켜지지 않습니다.

- 한 번만 보내기: 자녀 대화 화면에서 **현재 위치 공유**를 누릅니다.
- 자동 공유: 자녀가 대화에 `설정`을 보내고 **자동 위치 공유** 안내에 동의해 켭니다. 필요한 권한을 허용하세요.
- 중지: 자녀 설정이나 위치 공유 알림에서 언제든 끌 수 있습니다.

봇을 통한 대화는 텔레그램의 종단간 암호화 비밀대화가 아닙니다. 기록은 각 휴대폰에 저장되고 텔레그램을 거쳐 전달됩니다. 연결 해제는 이 휴대폰의 연결 정보와 앱 기록을 지우며, 상대 휴대폰과 텔레그램의 기록은 별도로 관리해야 합니다.

## 연결이 안 될 때

- **토큰 오류:** BotFather에서 해당 휴대폰용 봇의 토큰을 다시 복사합니다. 숫자와 `:`를 포함한 전체 토큰을 입력하세요.
- **상대 봇 연결 오류:** 상대방의 개인 텔레그램 계정 대신 **봇의 @사용자명**을 입력했는지 확인합니다. 두 봇의 Bot-to-Bot Communication Mode도 확인하세요.
- **계속 전송 대기:** 양쪽 휴대폰의 앱을 열고 메시지 수신을 켭니다. 같은 봇을 사용 중인 다른 수신 프로그램이나 기존 웹훅이 있으면 종료·해제해야 합니다.
- **토큰 노출:** BotFather에서 토큰을 재발급하고 해당 휴대폰에서 다시 연결하세요.
