# 우리집 칭찬톡 0.6.6

- 가족방 참여 시 자신을 제외한 모든 가족 봇에게 `@사용자명`으로 연결 인사(`hello`)를 보냅니다. 기존에는 방을 만드는 기기에서만 이 과정을 거쳤습니다.
- 인사에는 앱·프로토콜 버전·종류만 포함합니다. 대화 내용, 가족 이름, 방 코드, 위치, 봇 토큰은 넣지 않습니다. 응답한 개인 대화의 숫자 봇 ID가 명단에 저장된 ID와 일치해야 참여를 완료합니다.
- 다른 봇이 응답하거나 연결 확인이 실패하면 참여를 완료하지 않습니다. 확인이 끝나기 전에는 저장된 토큰·연결·가족방을 변경하지 않습니다. 받는 앱은 인사를 대화로 표시하거나 자동 응답하지 않습니다.

이미 참여한 기기는 업데이트만으로 인사를 보내지 않습니다. 기존 방 코드를 보관한 뒤 가족방 관리에서 **가족방 나가기 → 같은 코드로 다시 참여**하면 실행됩니다. 같은 코드의 저장된 대화·대기 메시지를 이어갑니다. 앱 삭제나 가족 연결 전체 초기화, 새 방 생성은 필요하지 않습니다. 나간 동안에는 해당 방의 송수신·위치·칭찬 동기화가 멈춥니다. 가족방만 연결된 자녀 기기는 나갈 때 자동 위치 공유가 꺼집니다. 이전에 공유 중이었다면 재참여 후 자동 위치 공유를 다시 켜 주세요.

[Telegram 공식 문서](https://core.telegram.org/bots/features#communication-in-private-chats)는 봇 간 개인 대화에 `@사용자명`을 사용하고 양쪽 봇의 Bot-to-Bot Communication Mode를 켜도록 안내합니다. 다만 [sendMessage 명세](https://core.telegram.org/bots/api#sendmessage)에는 숫자 대화 ID도 지원된다고 되어 있습니다. 참여 시 인사가 빠진 점을 보완하지만, 숫자 ID의 첫 전송이 항상 실패하거나 모든 400·403 오류의 원인이 같다고 단정하지 않습니다. 기존 참여 기기의 자동 복구나 오류 발생 시 추가 인사 재시도는 이번 변경에 포함하지 않습니다.

버전 코드는 19입니다. 기존 별 아이콘 복구, 기본 무음·단일 메시지 알림, 적응형 수신·위치 공유 주기는 유지합니다.
