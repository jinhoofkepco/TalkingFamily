# 우리 오는 길 0.4.3

자녀의 별 아이콘이 일시적인 실행·표시 실패로 꺼져 버리거나 잘못 눌러 사라지는 문제를 개선합니다.

- 별을 켜 둔 설정은 일시적인 오류나 예상치 못한 서비스 종료에도 유지합니다. Android가 허용하면 복구하며, 앱을 다시 열 때도 표시를 다시 시도합니다.
- 설정의 **별 아이콘 끄기**를 누르면 확인 창이 열립니다. **켜 두기**, 뒤로 가기, 창 바깥 누르기는 별 설정을 유지하고, **별 끄기**를 눌러야 꺼집니다. 자녀와 보호자 모두 적용됩니다.
- 실행 알림에서 한 번 눌러 별을 끄는 동작을 제거했습니다. 알림을 누르면 대화를 열 수 있습니다.
- 대화의 닫기 버튼은 계속 별 아이콘으로 돌아갑니다. 앱이 켜 둔 별을 복구할 때는 사용자가 보고 있던 대화 화면을 닫지 않습니다.
- 별을 켜거나 꺼도 자동 위치 공유 설정은 바뀌지 않습니다. 대화·칭찬·지도 안 타임라인과 기존 가족 연결·저장 기록을 유지합니다.

별은 Android의 실행 제한과 화면 위 표시 권한에 따라 늦게 복구되거나 표시되지 않을 수 있습니다. 강제 중지·재부팅 후에는 앱을 다시 열어 주세요. 직접 끈 별은 다시 켜지지 않습니다. 새로운 배터리 예외 권한이나 위치 권한을 추가하지 않습니다.

기존 앱을 삭제하지 않고 같은 서명의 APK로 업데이트합니다. 패키지는 `kr.family.homeway`, 버전 코드는 8입니다.

검증: 디버그 APK·기기 테스트 APK 빌드, JVM 테스트 94개, Android Lint를 통과했습니다. 새 정책 테스트는 켜 둔 별의 복구, 명시적으로 끈 설정 유지, 권한·가족 연결 해제 처리와 반복 표시 실패의 재시도 제한을 확인합니다. 끄기 확인·취소와 실제 별 창의 열기·닫기는 별도의 기기 검증 대상입니다.
