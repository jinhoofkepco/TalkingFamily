# 우리집 칭찬톡 0.6.5

- 화면을 껐다가 잠금을 해제한 뒤 별 아이콘이 복구되지 않는 경우를 수정합니다. 이전에는 화면 켜짐·잠금 해제 알림을 받은 순간 아직 잠겨 있으면 별을 숨긴 채 다음 화면 이벤트까지 기다렸습니다.
- 화면 켜짐·잠금 해제 이후 표시 조건을 제한된 횟수로 다시 확인합니다. 잠금 화면 위에는 별을 띄우지 않으며, 대화 화면을 열거나 화면을 다시 끄거나 별을 끄면 불필요한 재확인을 취소합니다. 지속 폴링이나 화면 깨우기 기능은 추가하지 않습니다.
- 별 아이콘의 마지막 화면 이벤트와 복구 상태, 메시지 수신 서비스의 최근 동작·대기 상태를 진단 출력으로 확인할 수 있습니다. 대화·이름·토큰·좌표는 진단에 포함하지 않습니다.

별 아이콘은 메시지 수신·위치 공유와 독립적인 화면 바로가기입니다. 이번 변경으로 수신·위치 공유 주기나 텔레그램의 재시도 대기를 바꾸지 않습니다. 기존 기본 무음·단일 메시지 알림 동작을 유지합니다. 버전 코드는 18입니다.
