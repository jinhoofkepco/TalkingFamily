# 우리 오는 길 0.4.0

가족 서버 없이 두 휴대폰이 텔레그램 봇으로 직접 대화하도록 연결 방식을 바꿨습니다.

## 연결 방법

1. Telegram의 BotFather에서 자녀용·보호자용 봇을 하나씩 만듭니다.
2. 두 봇 모두 **Bot-to-Bot Communication Mode**를 켭니다.
3. S23 일반은 자녀, S23 울트라는 보호자를 선택합니다.
4. 각 앱에 **자기 봇 토큰**과 **상대방 봇의 @사용자명**을 입력합니다.
5. 안내를 확인하고 우리 가족 연결하기를 누릅니다. 양쪽 연결을 마친 뒤 메시지 수신을 켭니다.

서버 주소, 가족 연결 키, 서버용 Telegram 설정, Firebase 프로젝트가 필요하지 않습니다. 봇 하나를 두 휴대폰에서 함께 사용하면 안 됩니다. 연결 과정에서 상대 봇으로 앱 연결 확인 메시지를 보냅니다. 토큰은 각 휴대폰의 Android Keystore로 보호해 저장하며 APK와 저장소에는 포함하지 않습니다.

## 동작

- 대화, 수동 위치, 동의한 자동 위치 공유, 높이 변화, 칭찬판과 약속·사용 승인을 유지합니다.
- 기록과 전송 대기열은 휴대폰 SQLite에 저장합니다. 재시도할 때 같은 기록 ID를 사용하며 스티커 중복 지급·차감을 막습니다.
- 상대 앱이 저장한 뒤 확인 응답을 보내야 **상대 기기 수신**으로 표시합니다. 사람이 읽었다는 뜻은 아닙니다.
- 화면을 닫아도 받으려면 양쪽의 **메시지 수신**을 켭니다. 지속 알림의 **수신 중지**로 끌 수 있습니다.
- 메시지 수신과 자동 위치 공유는 별개입니다. 위치 공유는 자녀의 명시적 동의와 위치 권한이 있어야 시작합니다.

## 설치 및 한계

기존 0.3.1 위에 삭제 없이 업데이트합니다. 패키지는 `kr.family.homeway`, `versionCode`는 5이며 기존 서명을 유지합니다. 이전 서버 방식으로 연결한 기기는 새 봇 연결 설정이 필요합니다.

절전·네트워크 차단·강제 종료·재부팅은 수신을 늦추거나 멈출 수 있습니다. 앱을 다시 열고 수신 상태를 확인하세요. 자동 위치 공유는 재시작 후 사용자가 다시 켭니다. Google 지도 키가 없으면 좌표와 외부 지도 열기를 사용합니다.

한쪽의 앱 데이터만 지우면 두 기기의 칭찬 기록이 달라질 수 있습니다. 연결을 초기화해야 할 때는 양쪽의 기존 기록과 대기 전송을 확인하고 함께 다시 설정하세요. 텔레그램 봇 통신은 종단간 암호화 비밀대화가 아닙니다.

실제 Telegram 계정 연결과 두 휴대폰 간 전달은 소유자의 봇 설정 후 확인해야 합니다. 자세한 입력 순서는 [서버 없는 연결 안내](../serverless-setup.md)를 참고하세요.
