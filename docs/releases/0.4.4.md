# 우리 오는 길 0.4.4

한 자리에 있는 휴대폰이 GPS 오차 때문에 이동한 것처럼 보이는 현상을 줄입니다.

- Android 활동 인식으로 정지·걷기·달리기·자전거·차량 이동을 구분하고, 정지 증거와 연속된 위치가 일치할 때 지도 표시 좌표를 보정합니다.
- 실제 GPS 측정 좌표·오차·시각은 그대로 보관합니다. 약 5분마다 새 위치를 확인하는 주기는 정지 중에도 유지합니다.
- 지도 안의 선택 시각 카드에 정지 추정 시간을 표시합니다. 마지막 기록 이후의 시간을 임의로 더하지 않으며, 오래된 활동 정보나 측정 중단 구간은 정지로 채우지 않습니다.
- 걷기·차량 이동이 확인되거나 GPS가 지속적으로 다른 장소를 나타내면 고정을 풀어 실제 이동이 계속 숨겨지지 않게 합니다.
- 자이로를 상시 추가 실행하지 않습니다. 활동 전환 이벤트와 5분 간격의 활동 확인을 이용하고, 결과는 기존 위치 기록에 함께 전송합니다.
- 신체 활동 권한이 없거나 활동 인식이 제공되지 않으면 원래 위치 공유를 유지합니다. 자녀 자동 위치 공유 설정에서 권한을 허용할 수 있습니다.
- 기존 가족 연결·메시지·위치 기록·별 아이콘 설정을 유지합니다. 학생과 부모 앱을 모두 업데이트해야 새 지도 보정 표시를 사용할 수 있습니다. 이전 기록에는 당시 활동 정보가 없어 소급 보정하지 않습니다.

휴대폰의 정지 상태를 추정하는 기능입니다. 학생의 실제 행동이나 정확한 실내 위치를 확정하지 않으며, Android의 감지 지연과 위치 오차에 영향을 받습니다. 배터리 절감률이나 현장 정확도 수치는 실측 전에는 보장하지 않습니다.

같은 서명으로 기존 앱 위에 업데이트합니다. 패키지 `kr.family.homeway`, 버전 코드 9입니다.
