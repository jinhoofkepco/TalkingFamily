# 우리집 칭찬톡 0.6.2

- 특정 가족에게 전달 대기일 때 상대 봇 조회 실패, Bot-to-Bot 설정 꺼짐, 전송 권한 거절을 구분해 안내합니다. 이전 버전의 공통 오류 문구가 원인을 구분하지 못하던 문제를 수정했습니다.
- 텔레그램이 상대 개인 대화를 찾지 못했다고 거절하면, 가족 명단의 봇을 다시 조회하고 저장된 봇 ID와 일치하는지 확인한 뒤 한 번 재시도합니다. 가족 대화와 부모·자녀 간 위치·칭찬 전달에 적용합니다.
- 확인되지 않은 사용자명으로 대화·위치 내용을 보내지 않으며, 응답 유실이나 요청 제한에는 즉시 중복 전송하지 않습니다. 한 가족의 연결 실패가 다른 가족의 전달을 막지 않도록 유지합니다.
- 새 메시지를 저장하면 진행 중인 수신 대기를 깨워 발송합니다. 보낼 메시지가 준비되어 있으면 10초 수신 대기를 건너뛰며, 서버가 요구한 재시도 대기는 지킵니다.
- 수신 메시지는 저장 직후 대화 화면에 반영합니다. 알림 뒤에 남은 네트워크 작업이나 5초 화면 갱신 주기를 기다리던 지연을 줄였습니다. 지난 대화를 많이 펼쳐 두어도 최신 메시지를 먼저 표시합니다.
- 연속 메시지와 수신 확인은 제한된 짧은 처리 묶음으로 전달하고, 대기 중에는 긴 수신 대기로 돌아갑니다. 기존 1:1 수신 확인이 많이 쌓여 가족 대화가 밀리는 경우도 줄였습니다.

기존 앱 위에 업데이트하면 가족방 코드, 설정, 대화와 전달 대기 기록을 유지합니다. 새 방을 만들 필요는 없습니다. 버전 코드는 15입니다.

실제 아들→딸 전송 실패 원문은 이전 앱이 저장하지 않아 아직 확정하지 못했습니다. 이 버전은 조회 실패 복구와 오류 구분을 보완하며, 실제 가족 기기의 왕복 전달 확인은 별도로 필요합니다. 자동 검사는 가상 Telegram 응답을 사용합니다.

메시지 지연 개선은 보내는 기기와 받는 기기 모두 업데이트하면 적용됩니다. 통신망과 Android 절전 상태에 따른 지연까지 일정 시간 이내로 보장하지는 않습니다.
