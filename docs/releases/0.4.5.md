# 우리 오는 길 0.4.5

0.4.4의 Android 활동 인식과 GPS 흔들림 보정 기능을 포함하며, 휴대폰이 이미 정지해 있을 때 업데이트하거나 자동 공유를 시작하는 경우를 보완합니다.

- 활동 전환 감시가 성공적으로 등록된 뒤 새로 측정한 신뢰도 높은 정지 상태로도 보정을 시작할 수 있습니다. 처음 정지 시작 이벤트가 오지 않더라도, Android가 장시간 정지 상태에서 보고를 쉬는 동안 보정이 불필요하게 풀리지 않도록 합니다.
- 감시 등록 이전의 캐시 측정값은 이 조건에 사용하지 않습니다. 진행 중인 걷기·차량 이동 상태를 단일 정지 측정값으로 지우지 않으며, 이후 이동·정지 종료·권한 해제와 GPS 모순에 따른 해제 처리는 유지합니다.
- 정지 여부와 관계없이 약 5분마다 새 위치를 확인합니다. 원본 GPS 값과 측정 시각은 보관하고, 지도 표시 좌표와 정지 추정 시간을 별도로 전달합니다.
- 지도 안에서 선택한 기록 시점의 정지 추정 시간과 GPS 흔들림 보정을 확인할 수 있습니다. 과거 기록에는 소급 적용하지 않습니다.
- 가족 연결·기존 기록·별 아이콘 설정은 유지합니다. 자이로를 상시 추가 실행하지 않습니다.

학생과 부모 폰 모두 최신 버전으로 업데이트해 주세요. 부모 0.4.4의 지도 표시도 학생 0.4.5의 기록과 호환됩니다.

같은 서명으로 기존 앱 위에 업데이트합니다. 패키지 `kr.family.homeway`, 버전 코드 10입니다.
