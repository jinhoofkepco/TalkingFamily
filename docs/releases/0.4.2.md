# 우리 오는 길 0.4.2

자녀의 자동 위치 공유를 켰는데도 5분 위치 기록이 빠지거나 앱 재실행 때 공유가 꺼지는 문제를 개선합니다.

- 공유 중에는 **움직임이 없어도 약 5분마다 새 위치를 요청**합니다. Android 위치 제공자의 정기 업데이트를 사용해 화면이 꺼졌을 때 앱 내부 타이머에만 의존하지 않습니다.
- 자녀가 동의하고 켜 둔 공유 설정을 예상치 못한 앱 종료에도 유지합니다. Android가 허용하면 공유 서비스를 복구하며, 앱을 다시 열 때도 기존 설정으로 공유를 이어갑니다. 직접 끄거나 가족 연결을 해제하면 다시 켜지지 않습니다.
- 위치 공유가 복구됐지만 메시지 수신 서비스가 없는 경우에도 저장된 기록의 전송을 이어갑니다. 저장 실패 시 같은 기록 ID로 재시도하며, 실제 저장이 완료된 뒤에만 저장됐다고 표시합니다.
- 자녀의 **자동 위치 공유** 설정에서 최근 자동 측정 시각과 전달 상태를 확인할 수 있습니다. **상대 기기 수신**은 보호자 앱이 기록을 저장하고 확인 응답을 보낸 상태이며, 사람이 읽었다는 뜻은 아닙니다.
- 기존 지도 안 타임라인, 대화·칭찬, 텔레그램 가족 연결과 저장된 기록은 유지합니다. 위치 공유를 처음 켤 때의 동의 절차도 유지합니다.

5분은 요청 간격이며 정확한 측정·전달 시각을 보장하지 않습니다. 위치 기능이 꺼져 있거나 위치 신호·절전·통신 상태가 좋지 않으면 기록이나 전송이 늦어질 수 있습니다. 강제 중지·재부팅 후에는 앱을 다시 열어 주세요. 공유는 자녀의 설정이나 실행 알림에서 끌 수 있습니다.

기존 앱을 삭제하지 않고 같은 서명의 APK로 업데이트합니다. 패키지는 `kr.family.homeway`, 버전 코드는 7입니다. 새 위치 권한이나 정확한 알람 권한을 추가하지 않습니다.

검증: 디버그 APK·기기 테스트 APK 빌드, JVM 테스트 90개, Android Lint를 통과했습니다. 테스트는 정지 중 주기 수집, 콜백 시간 차이·누락 후 복구, 저장 재시도와 중복 방지, 공유 동의 유지·중지, 수신 서비스가 없는 경우의 전송, 오래 보관된 위치의 수신 상태를 확인합니다. 실제 두 휴대폰의 화면 꺼짐·절전·위치 신호에 따른 장기 동작은 별도 확인이 필요합니다.
