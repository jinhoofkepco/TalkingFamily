# 우리집 칭찬톡 0.6.0

- 엄마·아빠 누구든 아들·딸을 선택해 위치와 지도 안의 시간별 기록을 확인합니다. 자녀 선택은 위치·칭찬판 탭에 함께 적용됩니다.
- 자녀별 스티커 잔액, 보상, 사용 요청을 나누고 부모 두 분이 함께 지급·편집·승인합니다. 같은 요청의 동시 승인은 한 번만 차감하고, 다른 부모가 먼저 바꾼 보상을 오래된 편집 내용으로 덮어쓰지 않습니다.
- 자녀 휴대폰에서 처리 결과를 확정해 부모에게 전달합니다. 자녀가 오프라인이면 부모의 변경은 대기하며, 연결 후 반영됩니다. 첫 동기화가 끝나기 전에는 잔액을 0으로 표시하지 않습니다.
- 위치·칭찬 기록은 명단의 엄마·아빠와 해당 자녀 사이에서만 전달합니다. 형제자매와 ‘가족’ 역할에는 보내지 않습니다. 가족 단체 대화는 기존처럼 명단 전체에 전달합니다.
- 기존 자녀 폰의 칭찬 기록과 기존 부모 폰에 남은 해당 자녀의 이동 기록을 보존합니다. 기존 1:1 대화·봇 연결·별 아이콘 설정도 유지합니다. 꺼진 자동 위치 공유를 업데이트로 켜지 않습니다.

가족 휴대폰 **모두 0.6.0 이상으로 업데이트**하세요. 기존 0.5.0 가족방 코드를 계속 사용할 수 있습니다. 부모 화면의 위치·칭찬판에서 자녀 이름을 선택합니다. 명단을 바꿀 때는 새 가족방 코드를 만들어 함께 참여합니다. 새로 참여하는 부모에게 다른 부모의 전체 과거 위치 보관함을 복사하지는 않습니다.

기존 앱을 삭제하지 말고 같은 서명의 APK를 그대로 설치하세요. 버전 코드는 13입니다. 봇 토큰이나 실제 가족 기록은 배포 파일에 포함하지 않습니다.

검증: JVM 테스트 196개, Android 15 에뮬레이터의 저장소·가족방·위치 기록·화면 검증 50개를 통과했습니다. 화면 테스트 3개는 스크롤 절차를 수정하고 해당 화면 테스트 8개를 다시 실행해 통과했습니다. 에뮬레이터를 시작한 직후에는 시험 시작 전 프로세스 준비 시간 초과가 있어 재실행했습니다. Android 정적 검사는 오류 0개이며, 동시 승인과 재전송은 가상 Telegram 응답으로 검증했습니다. 실제 가족 네 대의 계정 연결 시험은 포함하지 않습니다.
