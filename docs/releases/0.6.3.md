# 우리집 칭찬톡 0.6.3

- 대화 프로필에 이름을 두 글자까지 표시해 ‘서아’와 ‘서인’처럼 첫 글자가 같은 가족을 구분하기 쉽게 바꿉니다. 말풍선 위에는 전체 이름을 계속 표시합니다.
- 가족방 또는 기존 1:1 대화 화면을 실제로 보고 있을 때 빠르게 메시지를 수신합니다. 설정·지도·칭찬판, 별표만 표시된 상태, 화면 꺼짐·잠금 상태에는 배경 수신 정책을 적용합니다.
- 대화 화면을 닫으면 5초 뒤 확인합니다. 새 메시지가 없으면 다음 간격을 10→20→30→60초로 늘리고, 이후에는 60초를 유지합니다. 일반 배경 실행을 시작할 때도 60초를 기준으로 합니다.
- 어느 단계에서든 새로운 대화 메시지를 저장하면 그 시각부터 다음 확인을 5초 뒤로 잡습니다. 연속으로 메시지가 있으면 5초를 유지하고, 없으면 다시 간격을 늘립니다. 수신 확인(ACK)·위치 기록·중복 메시지는 새 대화로 세지 않습니다.
- 로컬에서 보낸 메시지와 위치 전송은 수신 확인 주기와 분리합니다. 이동 중 위치를 보내거나 전달을 재시도해도 배경 메시지 확인을 계속 빠른 주기로 바꾸지 않습니다. 텔레그램이 지정한 재시도 대기는 지킵니다.
- 가족방의 위치·칭찬 기록과 기존 1:1 전송은 수신 확인을 기다리는 동안에도 제한된 수의 다음 기록을 보낼 수 있습니다. 20초 위치 기록이 60초 수신 확인 때문에 계속 밀리는 것을 줄입니다. 전송 결과가 불확실하면 순서를 보존하며 재시도하고, 실제 전송한 기록의 인증된 수신 확인만 적용합니다. 업데이트 시 기존 대기 기록도 보존합니다.
- 수신 서비스가 실행 중일 때 대화 화면에서 반복하던 중복 네트워크 조회를 줄입니다. 받은 대화는 저장 직후 화면에 반영합니다.
- 움직임을 감지한 동안 위치 요청·기록 주기를 약 30초에서 20초로 바꿉니다. 움직임 근거가 사라지면 기존 유예 후 약 5분으로 돌아갑니다. 정지 위치 보정, 움직임 센서 확인, 계단·상하 이동 추정은 유지합니다.

Firebase·FCM·별도 가족 서버를 추가하지 않습니다. 기존 앱 위에 업데이트하면 가족방, 봇 설정, 대화와 전송 대기 기록을 유지합니다. 버전 코드는 16입니다.

배경 수신은 실제로 확인 간격을 늘리는 방식이므로, 조용한 상태에서 처음 도착한 메시지는 다음 확인까지 최대 약 60초 기다릴 수 있습니다. 상대 앱의 수신 확인(전달 수)과 부모에게 보이는 새 위치에도 받는 기기의 확인 주기가 적용됩니다. Android 절전·통신 상태에 따라 더 늦어질 수 있으며, 20초는 정확한 도착 시각을 보장하는 값이 아닙니다. 배터리 절감률과 실제 이동 성능은 별도 기기 측정이 필요합니다.
