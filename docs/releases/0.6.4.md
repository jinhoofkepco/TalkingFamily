# 우리집 칭찬톡 0.6.4

- 대화창과 홈 위에 나타나던 자동 안내·오류 배너를 제거합니다. 메시지의 전달 수와 입력 검증, 사용자가 직접 연 연결·권한 설정의 오류 안내는 유지합니다.
- 대화 화면을 실제로 보고 있을 때는 새 메시지 알림을 띄우지 않습니다. 대화창을 열면 기존 메시지 알림도 지웁니다. 설정·지도·칭찬판, 화면 꺼짐·잠금 상태에서는 메시지 알림을 받을 수 있습니다.
- 메시지별로 쌓이던 알림을 하나로 합칩니다. 연속 메시지는 같은 알림을 갱신하며 반복 소리·진동·팝업을 요청하지 않습니다.
- 메시지 알림은 기본 무음입니다. **설정 → 메시지 알림 → 알림 소리**에서 켤 수 있으며, 켜도 알림이 처음 나타날 때만 소리를 내고 같은 알림 갱신에는 다시 울리지 않습니다. Android에서 직접 변경한 채널 설정과 기존 알림 차단을 존중합니다.
- 이전 버전의 메시지 알림은 업데이트 후 앱을 시작할 때 정리합니다. 수신·위치 공유·별 아이콘의 실행 알림에는 영향을 주지 않습니다.
- 진단 기록은 휴대폰의 앱 전용 공간에 최대 256KiB 파일 두 개로 보관하고, 같은 기록은 60초 동안 중복 저장하지 않습니다. 진단용 고정 문구를 기록하며 대화 내용·가족 이름·봇 토큰·좌표·가족 코드는 기록하지 않습니다. 자동 업로드나 앱 안의 로그 메뉴는 추가하지 않습니다.

메시지 수신·위치 공유 설정과 0.6.3의 확인 주기는 유지합니다. 기존 앱 위에 업데이트하면 가족방·대화·설정을 보존합니다. 버전 코드는 17입니다.
