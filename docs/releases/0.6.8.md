# 우리집 칭찬톡 0.6.8

이미 전송을 시도한 기록이 개별 재시도로 남고, 늦은 수신 확인 때문에 묶음 기능이 해제되던 지점을 보완합니다. 밀린 데이터를 받는 동안에는 제한된 집중 동기화를 사용하고, 칭찬판은 버전을 비교해 필요한 변경분을 전달합니다.

- 묶음 지원이 확인된 상대에게 처음 발신하는 기록과 재시도 기록을 최대 16개씩 묶습니다. 원래 기록 ID, 내용 해시, 시각과 개별 수신 확인을 유지합니다. 실제 한 묶음 크기는 4,096자 및 압축 해제 후 64 KiB 제한에 따라 작아질 수 있습니다.
- 일반 중복 수신이 상대의 모든 확인 응답을 6시간 동안 개별 전송으로 바꾸지 않습니다. 묶음 응답이 계속 없거나 구버전 동작이 확인되면 제한된 개별 전송과 재협상으로 복구합니다. 기능 확인 요청이 밀린 데이터 뒤에 계속 밀리거나 일시적인 HTTP 실패 후 장시간 재시도되지 않던 조건을 보완합니다.
- 한 번에 가득 찬 수신 페이지, 처리할 확인 응답, 또는 실제 확인 응답 진행과 남은 발신 기록을 감지하면 약 1초 간격의 집중 수신을 사용합니다. 한 구간은 최대 30초 또는 20회이며, 빈 응답이 이어지면 일찍 끝납니다. 종료 후에는 30초 재진입 제한과 기존 5→10→20→30→60초 절전 주기를 적용합니다. 상대가 오프라인이라는 이유만으로 집중 수신하지 않습니다.
- 칭찬판 변경분 지원을 별도로 확인합니다. 부모가 알고 있는 기준 ID, 순서와 내용 해시를 보내면 자녀는 같은 기록에 전체 데이터를 다시 보내지 않습니다. 빠진 변경분을 순서대로 보내고 부모는 시작 순서와 적용 결과 해시를 확인한 뒤 저장합니다. 최초 연결, 보관 범위를 벗어난 변경, 누락 또는 불일치에는 전체 동기화를 사용합니다.
- 변경분 복구용 보관함은 자녀별 최근 1,024개 순서로 제한합니다. 기존 금융 기록의 중복 방지 ID와 이동 보관함은 이 제한으로 삭제하지 않습니다. 위치·칭찬 기록을 임의로 건너뛰거나 승인·잔액을 낙관적으로 확정하지 않습니다.
- 수신 기록, 확인 응답과 Telegram 수신 커서는 기존 SQLite 트랜잭션 안에서 저장합니다. Telegram의 429 응답과 지정 대기 시간은 집중 동기화 중에도 지킵니다.

버전 코드는 21, 로컬 데이터베이스 버전은 8입니다. 같은 서명의 새 APK를 덮어 설치하며 앱을 삭제하거나 가족방을 다시 만들 필요가 없습니다. 기존 수신·위치 공유 설정, 화면 밖 기본 무음 단일 알림과 이동 중 약 20초 위치 측정을 유지합니다.

변경분 동기화는 부모·자녀 양쪽에 0.6.8이 필요합니다. 개선된 묶음 재시도는 보내는 앱이 0.6.8이고 받는 앱이 0.6.7 이상이며 묶음 지원이 확인된 경우 사용할 수 있습니다. 모든 개선을 적용하려면 **가족폰 모두 0.6.8로 업데이트**하는 것을 권장합니다. 묶음이나 변경분을 지원하지 않는 이전 앱에는 기존 형식으로 전송합니다. 큰 과거 기록을 파일로 전송하는 기능과 최신 위치·과거 타임라인을 별도 전송하는 변경은 이번 범위에 포함하지 않습니다. 실제 처리 시간은 기록량, 상대 앱 실행 상태, 인터넷과 Telegram 제한에 따라 달라집니다.
