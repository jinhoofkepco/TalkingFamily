# 우리집 칭찬톡 0.4.6

가족 메신저와 칭찬판에 맞춰 앱 이름을 **우리집 칭찬톡**으로 바꾸고, 집 모양 말풍선과 칭찬 별을 담은 아이콘을 적용했습니다.

- 홈 화면 아이콘, 처음 안내 화면과 앱 이름을 새 디자인으로 통일했습니다. Android 테마 아이콘과 알림용 단색 아이콘도 제공합니다.
- 별 아이콘 창이 일시적으로 표시되지 않아도 실행 서비스를 종료하지 않습니다. 짧게 재시도한 후 화면 켜기·잠금 해제·앱 전환에 맞춰 다시 표시합니다.
- 별 아이콘 표시 여부를 확인할 때 봇 토큰을 복호화하지 않습니다. 일시적인 계정 접근 오류가 별 아이콘의 켜짐 설정을 지우지 않도록 보완했습니다.
- 별 아이콘의 켜짐 설정, 창 연결 상태와 복구 상태를 확인할 수 있는 개인정보 없는 기기 진단 정보를 추가했습니다.
- 사용자가 직접 끄거나 가족 연결을 해제하는 동작, 표시 권한 해제는 그대로 적용합니다. 잠금 화면에서는 별을 숨기고 잠금 해제 후 다시 표시합니다.

가족 연결, 대화·칭찬판·위치 기록과 GPS 흔들림 보정은 유지합니다. 기존 앱 위에 같은 서명으로 업데이트하며 패키지는 `kr.family.homeway`, 버전 코드는 11입니다.
