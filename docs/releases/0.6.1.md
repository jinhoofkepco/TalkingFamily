# 우리집 칭찬톡 0.6.1

- 움직임을 감지하면 자동 위치 공유 요청을 **약 30초 간격**으로 전환합니다. 움직임 근거가 사라지면 유예 후 **약 5분 간격**으로 돌아갑니다. GPS 좌표 흔들림만으로 이동 모드를 켜지 않습니다.
- 걸음과 기압을 함께 확인해 느린 상하 이동 감지를 보완하고, 기압 급변과 잡음으로 생기는 잘못된 이동을 줄입니다. 계단·경사로·엘리베이터를 확정 구분하지 않고 상대 높이 변화로 추정합니다.
- 부모 지도 안의 시간 막대에 올라가기·내려가기 시작과 종료, 상대 높이와 감지 근거를 표시합니다. 참고 GPS는 원래 측정 시각을 표시하며 상하 이동 좌표를 임의로 만들지 않습니다.
- 이동 시작 후 이전 정지 좌표 고정이 남는 경우를 보완하고, 위치 주기 교체 중 기록 저장과 Telegram 전송이 계속되도록 했습니다.

자동 위치 공유는 자녀가 켠 설정과 권한을 유지합니다. 자녀·부모 모두 0.6.1로 업데이트해야 새로운 감지 근거와 지도 표시를 함께 사용할 수 있습니다. 기존 앱을 삭제하지 말고 같은 서명의 APK를 설치하세요. 버전 코드는 14입니다.

30초는 Android에 요청하는 간격이므로 실제 측정·도착은 지연될 수 있습니다. 실내 GPS 오차나 정확한 층수 판정을 보장하지 않습니다. S23 실제 계단 실측 검증은 아직 포함하지 않습니다.

검증: JVM 자동 검사 243개 통과, APK 빌드 성공, Android 정적 검사 오류 0개. 기압·걸음 시험은 합성 센서 입력이며 가족 전달 시험은 가상 Telegram 응답을 사용했습니다.

구현 근거·동작·한계: [공식 문서와 공개 코드 검토](https://github.com/jinhoofkepco/TalkingFamily/blob/v0.6.1/docs/motion-and-height.md).
