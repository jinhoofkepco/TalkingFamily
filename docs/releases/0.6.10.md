# 우리집 칭찬톡 0.6.10

칭찬판이 최신 상태이면 부모에게 빠진 과거 위치를 다시 요청하지 않던 경로를 보완합니다. 위치 보관함을 별도로 복구하고, 지도 아래의 시간 선택 버튼을 안정적으로 배치합니다.

- 자녀의 전체 위치·상하 이동 보관함을 칭찬판의 변경 순서와 별개로 나누어 동기화합니다. 최초 복구는 남아 있는 보관함의 처음부터 시작하며, 각 페이지의 원본 ID와 내용이 모두 저장돼야 다음 페이지로 넘어갑니다. 중단 후에도 저장한 지점부터 재개합니다. 현재 위치 수신이나 칭찬판 동기화만으로 과거 기록을 완료 처리하지 않습니다.
- 과거 위치의 복구는 칭찬 잔액·승인·변경 순서에 영향을 주지 않습니다. 기존 기록·연결·자동 공유 설정을 유지하며 이미 삭제된 기록은 복구할 수 없습니다. 새 기록은 기존 전송으로 전달하고, 보관함 복구는 누락을 보완합니다.
- 대화·기존 1:1 전달·가족 기록 전송에 차례를 주어 한 종류의 대기가 다른 전송을 계속 밀어내지 않도록 합니다. Telegram의 요청 제한과 지정 대기 시간은 유지합니다.
- 위치와 칭찬 기록의 전송 실패도 진단 로그에 남깁니다. 저장 건수·대기 건수·지원 기능을 확인할 수 있는 진단을 추가하고, 실제 기록 조회 오류와 기존 오류 상태의 재표시를 구분합니다. 대화 내용·좌표·봇 토큰·가족방 코드는 진단에 남기지 않습니다.
- 지도 아래 시간 선택 영역은 이전·최신·다음 버튼을 고정된 행에 배치하고, 이전·다음에 48dp 터치 영역을 확보합니다. 선택한 시각과 날짜를 위에 표시하며 활동·계단·GPS 보정 설명은 버튼 위치를 바꾸지 않습니다. 날짜와 과거 시각의 수동 선택은 새 위치가 와도 유지합니다.

버전 코드는 23, 데이터베이스 버전은 10입니다. 같은 서명의 APK를 덮어 설치하면 기존 데이터를 유지합니다. 앱을 삭제하거나 가족방을 다시 만들 필요가 없습니다.

전체 보관함 복구에는 **자녀와 부모 모두 0.6.10 이상**이 필요합니다. 이전 앱과는 기존 전송을 유지합니다. 모든 기록의 도착 시간은 보관함 크기, 양쪽 앱 실행 상태, 인터넷과 Telegram 제한에 따라 달라집니다.
