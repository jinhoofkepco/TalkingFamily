# 우리집 칭찬톡 0.5.0

- 엄마·아빠·아들·딸 등 2~8명이 함께 대화하는 가족방을 추가했습니다. 방을 만든 뒤 같은 가족방 코드로 참여합니다. 휴대폰마다 자신의 텔레그램 봇을 사용하며 서버를 준비할 필요가 없습니다.
- 이름별 말풍선, 연속 메시지 묶음, 작은 시간 표시, 접이식 빠른 답장으로 한 화면에 더 많은 대화를 보여 줍니다. 이전 대화를 읽는 동안 새 메시지가 와도 읽던 위치를 유지합니다.
- 각 가족 기기의 전달 상태를 따로 저장하고 미수신 메시지를 재전송합니다. `2/3 전달`은 앱의 수신 확인이며 읽음 표시는 아닙니다.
- 가족방과 예전 1:1 대화를 분리하고 대화 기록을 별도로 보관해 이전 기록을 계속 불러올 수 있습니다. 기존 위치·칭찬판과 봇 연결, 별 아이콘 설정은 유지합니다.

모든 가족이 0.5.0 이상을 설치하고 각 봇의 Bot-to-Bot Communication Mode를 켜 주세요. 위치·칭찬판은 기존 1:1 연결 상대와만 사용합니다. 가족방 명단을 바꾸려면 새 방 코드를 만들어 함께 참여합니다.

기존 앱을 삭제하지 말고 같은 서명의 APK를 그대로 설치하세요. 이 릴리스는 버전 코드 12를 사용합니다. 봇 토큰이나 실제 가족 기록은 배포 파일에 포함하지 않습니다.

검증: JVM 테스트 176개, Android 15 에뮬레이터에서 가족방 저장·참여·화면 테스트 21개와 기존 위치 기록·1:1 설정·별 아이콘 회귀 항목 9개를 확인했습니다. 별 아이콘 복구 항목은 첫 시작 대기에서 시간 초과가 나 단독 재실행 후 통과했습니다. 새 가족방 전송 검증은 가상 Telegram 응답을 사용했으며 실제 가족 4대의 계정 연결 시험은 포함하지 않습니다.
