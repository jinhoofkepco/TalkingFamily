# 우리 오는 길 0.3.1

기존 별 아이콘과 대화 기능을 유지하면서, 같은 서명으로 계속 업데이트할 수 있도록 APK 배포를 정리한 버전입니다. 패키지는 `kr.family.homeway`, `versionCode`는 **4**입니다.

## 설치와 업데이트

[0.3.1 릴리스](https://github.com/jinhoofkepco/TalkingFamily/releases/tag/v0.3.1)에서 `TalkingFamily-0.3.1.apk`를 내려받습니다. **0.1.0·0.2.0·0.3.0을 이미 설치했다면 앱을 삭제하지 않고 그대로 업데이트**합니다. 같은 버전 APK를 다시 설치할 때도 기존 앱 위에 설치합니다. 먼저 삭제하면 휴대폰의 연결 설정과 로컬 기록은 사라집니다.

이전 APK와 같은 인증서를 보존한 `release` 빌드이며 앱 디버깅은 꺼져 있습니다. 개인용 직접 설치에 사용합니다. 키 보관과 이후 버전 배포 절차는 [서명·업데이트 관리](https://github.com/jinhoofkepco/TalkingFamily/blob/v0.3.1/docs/SIGNING.md)에 있습니다.

## 별 아이콘 사용

처음에는 앱 안내와 가족 연결 또는 체험 설정을 마친 뒤 **권한 설정 열기 → 다른 앱 위에 표시**를 허용합니다. 그다음 앱 아이콘으로 실행하면 화면 가장자리의 반투명 별로 시작합니다.

- 별을 누르면 대화가 열립니다. **닫기(X)** 또는 뒤로가기로 별로 돌아갑니다.
- 보이는 별은 약 **5 × 5mm**이고 투명한 터치 영역은 **48dp**입니다. 끌어 옮긴 위치를 기억합니다.
- 자녀는 정확히 `설정` 보내기 → **별 아이콘**, 보호자는 **칭찬판 → 가족 연결**에서 설정합니다.
- 별 알림에서 끌 수 있으며, 다음에 앱 아이콘으로 직접 실행하면 다시 별로 시작합니다.
- 별을 켜거나 꺼도 자동 위치 공유 설정은 바뀌지 않습니다. 별 자체는 GPS·센서·네트워크를 사용하지 않습니다.

## 연결과 확인 범위

**연결 없이 먼저 체험하기**는 예시 대화·위치·칭찬판을 사용하며 실제 위치를 수집하거나 전송하지 않습니다. 실제 두 기기 사이의 통신에는 Telegram 봇·HTTPS 중계 서버·기기 연결 키 설정이 필요합니다. 앱 안 Google 지도와 잠금화면 푸시는 지도 키와 Firebase 설정 후 빌드해야 합니다. [전체 설치 안내](https://github.com/jinhoofkepco/TalkingFamily/blob/v0.3.1/README.md#실제-두-휴대폰-연결)를 참고하세요.

0.3.0에서 Android 15 에뮬레이터의 가족 화면과 별 오버레이 동작을 검증했습니다. 이번 0.3.1에서는 다음을 추가로 확인했습니다.

- 보존한 PKCS12 키로 릴리스 빌드 성공, 기존 APK와 인증서 일치, Kotlin 단위 테스트 25개 통과, 릴리스 Lint 오류 0개.
- 에뮬레이터에서 0.3.0(`versionCode` 3) 위에 0.3.1(`versionCode` 4) 업데이트 설치 성공.
- 같은 0.3.1 APK를 다시 덮어쓰기 설치하는 과정도 성공.
- 두 설치 과정 전후의 연결 설정·체험 데이터·별 위치 설정·로컬 데이터베이스 파일 해시가 동일하여 데이터 보존 확인.
- 서명 키 파일이 없을 때 빌드가 실패하며 임시 키로 대체되지 않는 것 확인.

실제 S23 일반·S23 울트라와 실제 Telegram 계정은 아직 연결해 시험하지 않았습니다. 두 휴대폰에서 별의 크기·잠금 해제·One UI 절전 동작, 위치 감지 정확도와 배터리 소모를 확인해야 합니다.
