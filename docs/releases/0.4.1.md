# 우리 오는 길 0.4.1

보호자 앱의 **자녀 위치** 탭에서 날짜와 시간을 따라 이전 위치를 살펴보고, 선택한 기록을 앱 안의 지도에서 바로 볼 수 있습니다. Google 지도 앱을 열거나 지도 API 키를 설정할 필요가 없습니다.

- 날짜 선택과 시간별 타임라인을 추가했습니다. 위치·오르내림 기록을 최근 시각부터 보여 주며, 위치 기록을 누르면 그 시각의 지도로 이동합니다. **최신 기록**으로 돌아오거나 이전 날짜를 선택할 수 있습니다.
- 위치 기록을 별도 로컬 데이터베이스에 보관해 최근 대화 목록에서 빠진 뒤에도 날짜별로 볼 수 있습니다. 업데이트 시 현재 휴대폰에 남아 있는 기록을 옮깁니다. 이전 버전에서 이미 사라진 기록은 복구하지 못합니다. 가족 연결을 초기화하면 해당 휴대폰의 보관 기록도 지워집니다.
- OpenStreetMap 지도에 선택한 위치와 오차 범위를 표시합니다. 지도를 손가락으로 이동·확대·축소하고 **표시 위치로** 버튼으로 돌아올 수 있습니다.
- 새로운 위치를 받으면 표시점을 갱신합니다. 부모가 보고 있던 확대 수준과 지도 범위는 유지합니다.
- 지도 위의 **자동 공유 설정 켜짐/꺼짐** 카드를 제거해 지도가 먼저 보입니다.
- 앱 안에 뜨던 일반 동작 안내 배너를 제거했습니다. 실제 연결·입력 오류는 계속 확인할 수 있습니다.
- 앱 밖의 새 알림은 상대방의 대화 메시지만 표시합니다. 위치·칭찬 알림은 보내지 않습니다. Android가 요구하는 메시지 수신·위치 공유·별 아이콘 실행 알림은 무음으로 유지합니다.
- **가족 연결 → 실행 알림 표시 설정**에서 실행 알림별 Android 설정을 바로 엽니다. 해당 알림 종류의 허용을 끄면 대화 메시지 알림을 유지하면서 실행 알림을 숨길 수 있습니다. 위치 공유 알림은 자녀의 **자동 위치 공유 → 위치 공유 알림 표시 설정**에서도 조절할 수 있습니다. Android의 실행 중인 앱 목록이나 위치 사용 표시는 시스템에 따라 남을 수 있습니다.
- 측정 시간·좌표·오차와 오래된 위치 안내는 지도 아래에 남깁니다. 지도 연결이 실패하면 다시 보기 버튼을 제공하며 좌표는 계속 확인할 수 있습니다.

기존 텔레그램 가족 연결, 메시지 수신, 자녀의 위치 공유 설정과 저장 기록을 유지하는 업데이트입니다. 자녀 앱이 0.4.0이어도 부모 앱 0.4.1과 통신할 수 있습니다. 동일한 앱 서명을 사용하며 패키지는 `kr.family.homeway`, 버전 코드는 6입니다.

지도는 인터넷으로 화면에 보이는 부분만 불러옵니다. 지도 제공자인 OpenStreetMap에는 타일 요청에 따른 열람 지역과 IP 주소가 전달됩니다. 봇 토큰·대화·자녀 이름은 지도에 전달하지 않습니다. 지도 사용은 부모 휴대폰의 GPS 권한을 요구하지 않습니다.
