# 우리집 칭찬톡 0.6.9

가족방의 밀린 이동 기록을 받는 동안 현재 위치까지 기다려야 하던 동작을 개선합니다. 최신 위치를 별도로 먼저 전달하고, 큰 기록 묶음은 텔레그램 압축 파일로 보냅니다.

- 자녀별 현재 위치를 위한 전송 슬롯과 저장 공간을 추가합니다. 새 위치는 이 슬롯을 갱신하며, 모든 원본 위치·오르내림 기록은 기존 보관함과 전달 대기에 남습니다. 현재 위치 수신만으로 과거 기록의 전달을 완료하거나 칭찬판의 승인·잔액·변경 순서를 바꾸지 않습니다.
- 부모 지도는 과거 타임라인을 불러오는 중에도 최신 위치를 표시합니다. 날짜나 시간 막대에서 직접 고른 과거 기록은 새 위치가 와도 유지하며, **최신**을 누르면 현재 위치로 돌아갑니다. 서로 다른 날짜의 기록을 임의로 경로로 잇지 않습니다.
- 파일 지원이 확인된 상대에게 많은 기록을 최대 128개씩 gzip 파일로 묶습니다. 작은 묶음은 기존 텍스트 전송을 사용하며, 파일은 압축 전 512 KiB·압축 후 256 KiB로 제한합니다. 원래 기록 ID, 내용, 시각과 개별 수신 확인은 유지합니다.
- 파일 다운로드는 데이터베이스 잠금 밖에서 수행합니다. 한 번의 수신 처리에서 파일을 최대 두 개 내려받고, 원본 기록·수신 확인·수신 커서는 함께 저장합니다. 일시적인 다운로드 실패에는 같은 지점부터 재시도하고 Telegram의 지정 대기 시간을 지킵니다. 연결·서버 오류가 세 번 이어진 파일이나 잘못된 파일에는 완료 확인을 보내지 않고 뒤의 메시지 처리를 이어가 원본 재전송으로 복구할 수 있게 합니다. Telegram의 요청 제한·인증 오류나 저장 실패에는 이 건너뛰기를 적용하지 않습니다.
- 파일과 최신 위치 지원은 각각 협상합니다. 이전 앱에는 기존 전송을 사용하고, 지원이 사라지거나 확인 응답이 계속 없으면 기존 방식으로 복구합니다. 기존의 제한된 집중 동기화와 칭찬판 변경분 전송도 유지합니다.

버전 코드는 22, 로컬 데이터베이스 버전은 9입니다. 같은 서명의 APK를 덮어 설치하면 기존 연결·기록·설정을 유지합니다. 앱을 삭제하거나 가족방을 다시 만들 필요가 없습니다. 이동 중 약 20초 위치 측정, 평소 절전 수신 주기와 기본 무음 단일 메시지 알림은 유지합니다.

최신 위치 별도 전달과 압축 파일 전송에는 **보내는 쪽과 받는 쪽 모두 0.6.9**가 필요합니다. 이번 개선은 가족방에 적용합니다. 기존 1:1 연결은 기존 전송을 이어갑니다. 실제 처리 시간은 기록량, 상대 앱 실행 상태, 인터넷과 Telegram 제한에 따라 달라집니다. Firebase나 별도 중계 서버는 추가하지 않습니다.
