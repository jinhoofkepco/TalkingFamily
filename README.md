# 우리 오는 길

갤럭시 S23·S23 울트라에서 사용할 보호자와 자녀의 Android 앱입니다. 하나의 APK를 두 휴대폰에 설치하고 역할을 선택합니다. Kotlin/Jetpack Compose 앱과 Node.js/SQLite 중계 서버가 포함되어 있습니다.

## 구현한 동작

- **자녀 화면은 대화가 기본**입니다. 하단 메뉴 없이 오른쪽 위 칭찬판을 누르면 팝업이 열립니다. 대화 입력란에 공백 없이 정확히 `설정`을 보내면 자동 위치 공유·별 아이콘·공유 정보·가족 연결 메뉴가 열리며 이 명령은 보호자에게 전송되지 않습니다. 대화 안의 `현재 위치 공유`가 새 위치를 한 번 측정합니다. 자동 공유 설정을 켜지 않아도 수동으로 보낼 수 있습니다.
- **보호자 화면은 대화·자녀 위치·칭찬판**입니다. 별 아이콘으로 열면 대화 화면이 열립니다. 위치 탭은 상단 앱 제목과 설정 아이콘 없이 자동 공유 상태부터 표시합니다. 수동 위치와 자동 기록을 실제 측정 시각, 정확도와 함께 확인합니다. 위치 탭을 열었는지와 관계없이 자녀의 자동 공유 세션이 기록을 만듭니다.
- 자녀가 고지를 읽고 **자동 위치 공유에 동의해 켰을 때만**, 움직임을 감지합니다. 각 5분 구간에 움직임이 있었다면 새 위치를 요청합니다. 정지한 구간은 GPS 요청을 생략합니다. 수동 요청은 이 주기와 별개입니다.
- 기압과 움직임으로 `올라가기 시작`, `올라가기 종료`, `내려가기 시작`, `내려가기 종료`를 독립된 이벤트로 기록합니다. 5분을 기다리지 않고 이벤트가 감지되면 전송 대기열에 넣습니다. 종료는 높이가 안정된 것을 확인한 뒤 이전 이동 시각으로 기록합니다.
- 칭찬을 한 장씩 지급하고, 보호자가 **칭찬판 → 우리의 약속 → 관리**에서 선물 이름과 필요한 스티커 개수(1~999개)를 추가·수정·삭제합니다. 자녀는 정해진 약속을 골라 사용 요청을 보냅니다. 약속을 수정·삭제해도 이미 접수된 사용 요청의 이름과 개수는 유지됩니다. 보호자가 승인한 경우에만 차감됩니다. 중복 요청과 재전송으로 두 번 차감되지 않습니다.
- 첫 실행 고지, 별도 자동 공유 동의, Android 권한 요청, 공유 중 지속 알림, 즉시 중지 기능을 포함합니다. 보호자 화면에서 자녀의 자동 공유를 몰래 켤 수는 없습니다.
- 기기 오프라인 기록은 로컬 SQLite에 보관하고 연결 시 재시도합니다. 봇 토큰은 서버에만 보관하며 기기 연결 키는 Android Keystore로 암호화합니다.

## 먼저 화면 보기

[최신 APK 내려받기](https://github.com/jinhoofkepco/TalkingFamily/releases/latest)에서 `TalkingFamily-버전.apk`를 받습니다. **이미 설치했다면 앱을 삭제하지 말고 새 APK를 그대로 설치**하세요. 기존 0.1.0~0.3.0과 같은 서명을 유지하며, 다음 버전도 같은 키와 증가한 버전 번호로 배포합니다. 자세한 내용은 [서명·업데이트 관리](docs/SIGNING.md)와 [0.3.1 설치 안내](docs/releases/0.3.1.md)에 있습니다. Android Studio로는 `android/` 폴더를 엽니다.

앱 첫 화면 아래의 **연결 없이 먼저 체험하기**를 누르면 서버나 키 없이 동작을 확인할 수 있습니다. 자녀는 `설정` 메시지 → 가족 연결, 보호자는 칭찬판 하단 `가족 연결`에서 체험 역할을 바꾸고 대화, 위치 기록, 칭찬 지급·사용 승인을 체험합니다. 이 모드는 예시 위치를 사용하며 실제 센서 수집이나 전송을 하지 않습니다. 서울시청 부근의 예시 좌표이며 가족의 위치가 아닙니다.

## 별 아이콘으로 대화 열기

처음 실행할 때 기존 안내와 연결 또는 체험 설정을 마치고, 별 아이콘 안내에서 **권한 설정 열기 → 다른 앱 위에 표시**를 허용합니다. 권한이 유지되면 이후 앱 아이콘을 눌러 실행할 때 보호자·자녀 모두 작은 반투명 별로 시작합니다. 별을 누르면 전체 대화가 열리고, **닫기(X)** 또는 뒤로가기를 누르면 별로 돌아갑니다. 열린 팝업은 뒤로가기로 먼저 닫습니다. 권한을 허용하지 않아도 앱 안에서 대화할 수 있습니다.

보이는 별은 약 **5 × 5mm**, 투명한 터치 영역은 **48dp**입니다. 끌어서 위치를 바꾸면 가까운 화면 가장자리에 붙고 위치를 기억합니다. 자녀는 정확히 `설정` 보내기 → **별 아이콘**, 보호자는 **칭찬판 → 가족 연결**에서 켜고 끕니다. 알림의 **별 아이콘 끄기**로도 종료할 수 있습니다. 끈 뒤 다음에 앱 아이콘으로 직접 실행하면 다시 별로 시작합니다.

별을 켜거나 꺼도 자동 위치 공유 설정은 바뀌지 않습니다. 별 자체는 GPS·센서·네트워크를 사용하지 않습니다. 잠금 화면에서는 숨기며 재부팅·시스템 종료 후 자동으로 재시작하지 않습니다. 체험 모드에서도 별은 실제 화면 위에 표시됩니다. 실제 S23 두 기기의 크기·잠금 해제·One UI 절전 동작은 아직 검증하지 않았습니다.

## UI 검토본

`ui-mockup/index.html`은 검토에 사용한 독립 HTML입니다. 실제 앱은 같은 화면 흐름을 사용하며 위치·메시지·약속은 연결 상태와 서버 응답을 반영합니다. 약속 목록은 텔레그램 경유 완료 후 두 기기에 반영되며 전송 대기·실패는 구분해서 표시합니다.

## 실제 두 휴대폰 연결

아래 설정은 아직 사용자 계정에 연결하지 않았습니다. 비밀키를 채팅이나 저장소에 올리지 말고 해당 로컬 파일에 입력합니다.

1. **중계 서버**: [서버 설치 안내](server/README.md)에 따라 Node.js 22.13 이상에서 `npm ci`, `npm run setup`을 실행합니다. 생성된 `server/.env`에 보호자 소유의 Telegram 봇 두 개를 설정하고 두 봇의 Bot-to-Bot Communication Mode를 켭니다. 인터넷에서 접근 가능한 HTTPS 주소로 서버를 운영합니다.
2. **Google 지도**: Google Cloud에서 Maps SDK for Android를 활성화하고 결제 계정과 앱 제한을 설정합니다. `android/local.properties`에 `MAPS_API_KEY=...`를 추가합니다. 패키지 이름은 `kr.family.homeway`이며 앱 서명 SHA-1 제한도 설정합니다. 키를 넣고 APK를 다시 빌드하면 앱 안에 지도가 표시됩니다. 키가 없으면 좌표와 외부 Google 지도 열기 버튼을 제공합니다.
3. **잠금화면 알림**: Firebase 프로젝트에 같은 Android 패키지를 등록하고 `google-services.json`을 `android/app/`에 둡니다. 서버에는 해당 프로젝트 서비스 계정 파일 경로를 설정합니다. 파일을 넣은 뒤 APK를 다시 빌드해야 합니다. 설정하지 않으면 앱을 열어 둘 때 새 기록을 가져오지만 잠금화면 푸시는 동작하지 않습니다.
4. **설치와 연결**: 두 휴대폰에 같은 APK를 설치합니다. 보호자·자녀 각각의 역할과 HTTPS 서버 주소, `server/.env`의 해당 기기 연결 키를 입력합니다. 이 기기 키는 Telegram 봇 토큰과 다릅니다.
5. **위치 공유**: 자녀 앱의 대화에서 수동 위치 공유를 시험합니다. 대화에서 정확히 `설정`을 보내고 자동 위치 공유 메뉴의 안내를 읽고 동의한 뒤 정확한 위치, 신체 활동, 알림 권한을 허용합니다. 공유 중 알림의 종료 버튼으로도 중지할 수 있습니다.

Google 지도는 위치를 중심으로 동네가 보이도록 시작합니다. 표시 범위를 고정해서 아이가 화면 밖으로 사라지게 하지는 않습니다. 지도 제한 키와 Firebase 설정은 APK 빌드 시 적용하고, 가족 서버 주소·기기 키는 설치 후 입력합니다.

## 빌드와 검증

필요 환경: JDK 17, Android SDK 35, Node.js 22.13 이상. Gradle Wrapper가 포함되어 있습니다.

가족 휴대폰에 설치할 APK는 고정 서명을 적용한 `release` 빌드를 사용합니다. 로컬 서명 설정과 GitHub Actions 배포 절차는 [서명·업데이트 관리](docs/SIGNING.md)를 따릅니다. 다른 컴퓨터에서 별도 서명으로 만든 디버그 APK는 기존 설치본 위에 업데이트할 수 없습니다.

```sh
cd android
# local.properties에 sdk.dir=/내/Android/sdk 경로 설정
./gradlew :app:assembleDebug :app:testDebugUnitTest :app:lintDebug
# 테스트용 Android 기기 또는 에뮬레이터가 연결돼 있을 때
./gradlew :app:connectedDebugAndroidTest
```

```sh
cd server
npm ci
npm test
```

- 단위 테스트: 약속 목록 저장·수정·삭제·기존 캐시, 권한과 사용 요청 스냅샷, 전송 실패 정보 파싱. 센서는 정지·움직임 누적, 5분 주기, 실패 후 재시도, 기압 잡음·드리프트, 상승·하강, 방향 반전, 센서 공백.
- 서버 테스트: 인증·권한, 실제 로컬 HTTP를 통한 가짜 Telegram 왕복, 수신 검증, 재시작, 스티커 원자적 차감과 중복 방지, 푸시 대기열.
- 에뮬레이터 UI 테스트: 자녀 전체 대화와 칭찬판 팝업, 정확한 `설정` 명령 구분, 보호자의 네 가지 높이 이벤트, 약속 관리→자녀 선택→승인, 체험 모드에서 추적 서비스 미실행. 실제 오버레이 권한 허용·거부·철회, 별 이동·위치 저장, 대화 열기·닫기·뒤로가기, 화면 재생성, 알림에서 별 종료도 확인합니다.

## 해석과 한계

**5분은 요청 간격 기준이며 Android가 정확한 실행 시각을 보장하지 않습니다.** 화면 꺼짐, 절전 설정, 센서 이벤트 전달 지연, GPS 수신 상태에 따라 늦어질 수 있습니다. 무제한 wake lock이나 정확 알람을 사용하지 않습니다. 앱 강제 중지·재부팅 후에는 자동으로 위치 수집을 재개하지 않으며 자녀가 다시 켭니다. 서버에서 마지막 받은 공유 설정과 실제 연결 상태를 구분하고 오래된 기기 상태를 경고합니다.

현재 위치 요청은 캐시를 사용하지 않고 새 위치를 기다립니다. 20초 이상 지난 위치나 오차 150m를 넘는 측정은 전송하지 않습니다. 자동 측정 실패 시 다음 구간에서 다시 시도합니다. 실내에서는 높이 이벤트만 기록되고 새 GPS 기록이 없을 수 있습니다.

높이는 **상대 변화의 추정**입니다. 현재 몇 층인지, 특정 건물에 들어갔는지, 계단인지 엘리베이터인지 확정하지 않습니다. 기본 검출은 약 1.8m 이상 변화와 움직임을 확인하고, 약 8초 동안 높이 변화가 안정되면 종료를 판단합니다. 날씨·실내 압력·휴대 방식·계단 중간 정지에 영향받을 수 있으므로 S23 실제 기기에서 보정해야 합니다. 중간에 멈추면 이동 기록이 둘로 나뉠 수 있습니다.

**전송 대기**는 기기나 서버에서 재시도 중이며, **텔레그램 경유 완료**는 상대 봇까지 수신된 상태입니다. 상대 휴대폰 도착이나 읽음 확인을 뜻하지 않습니다. Telegram과 FCM은 인터넷 연결이 필요합니다.

현재 서버 기록은 운영자가 삭제할 때까지 보관합니다. 앱 연결을 해제해도 서버·백업·Telegram 기록은 삭제되지 않습니다. 삭제 방법은 서버 안내에 있습니다. Telegram 봇 대화는 종단간 암호화 비밀대화가 아닙니다.

## 실제 사용 전 S23 확인

두 기기의 현재 Android/One UI 버전에서 수동 위치, 잠금화면 메시지 알림, 자동 공유 중지, 5분 이동/정지 구간을 확인합니다. 같은 계단에서 올라가기·멈춤·내려가기와 엘리베이터를 각각 시험하고 실제 시각과 비교합니다. 인터넷을 잠시 끊었다 연결해 기록 시각이 보존되는지, 재부팅 시 공유 상태가 오해되지 않는지 확인합니다. 이 저장소에서는 실제 S23과 실제 계정 키를 연결하지 않았으므로 배터리 소모와 현장 감지 정확도는 아직 측정하지 않았습니다.
